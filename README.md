# まなびピン

子どもと先生のための学習サイト集です。ピンをながめるように、学習に使えるサイトを見つけられます。

- 公開ページ：https://eduwithdai.github.io/manabi-pin/
- 「子ども向け」「先生・保護者」「自主学習」の3つのタブ
- 教科・学年・種類（WEBサイト／動画／プリント／オンライン学習）と、テーマ（夢・生きる・じぶん・絆・つくる）でしぼりこみ
- 自主学習タブ：学年ごとのおすすめを出す「シャッフル」と、質問に答えると好きなことが見つかる「すきしんだん」
- 保存したピンや「見たよ」の記録は、その端末のブラウザの中だけに保存されます（外部には送信しません）
- 各サイトの内容・画像の権利は、それぞれのサイトの運営者にあります。画像には出どころを表示しています
